# Evidências de Funcionamento — LifeCycle IAM

Esta pasta contém capturas de tela que demonstram o funcionamento do projeto LifeCycle IAM durante os testes realizados em ambiente local.

## Imagens

**01 — Menu Principal**

Apresenta as opções disponíveis no sistema para gerenciamento do ciclo de vida dos colaboradores.

**02 — Consulta de Colaboradores**

Demonstra a consulta dos colaboradores cadastrados e seus respectivos status.

**03 — Histórico de Auditoria — Registros 1 a 4**

Apresenta os registros das operações realizadas e armazenadas no banco de dados.

**04 — Histórico de Auditoria — Registros 5 a 7**

Demonstra a continuidade do histórico de auditoria e a rastreabilidade das operações.

## Observação

Os testes foram realizados em ambiente local, utilizando dados fictícios. O projeto não executa operações em contas corporativas reais.
